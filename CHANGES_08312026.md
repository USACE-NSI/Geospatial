### #9 — attribute coercion null-safety
`AttributeColumn.Coerce` (and therefore `AttributeTable.Coerce` / `CoerceRow`)
returned a `NullReferenceException` on `null` input because the old
`recordVal` called `val.ToString()` unconditionally. Now returns `null`.
Covered by `AttributeTableTests.Coerce_NullYieldsNull_NotThrow`.

### #10 — FindUniques → Distinct
The old `FindUniques` helper was removed; `CsvHelper.ReadUniqueColumn` derives
unique values with `Distinct(StringComparer.OrdinalIgnoreCase)` over the
parsed column.

### #11 — CSV trailing-null NRE
The old `ReadCSVtoDict` did a naive `string.Split(',')` and crashed on the
trailing null read at EOF. It's gone; `CsvHelper` now uses a quote-aware
line parser (`ParseLine`) so embedded commas/quotes/newlines round-trip.
Covered by `CsvRoundTripTests.WriteThenRead_QuotingPreserved`.

### #15 — BoundingBox closed-interval overlap
`BoundingBox.Overlaps` now uses the correct closed-interval test
(`MinX <= other.MaxX && other.MinX <= MaxX && MinY <= other.MaxY &&
other.MinY <= MaxY`). The original test —
`(queryMax in [min,max]) || (queryMin in [min,max])` — returned 0 when the
query box fully *contained* the node box. This is the **new** geometry
primitive used by refactored code. **It is not a fix to the legacy R-tree:**
`RTreeNode.getMBRoverlap` still carries the original gate logic, restored
verbatim on purpose (see below).

## Unnumbered `fix:` markers

- **`Feature.cs` (class doc)** — replaces the old `Feat` parallel lists
  (`_parts[i]` / `_vertices[i]` / row `i`) where any add/remove on one list
  silently desynced the others. Geometry and attribute row now live on one
  `Feature` object.
- **`Part.cs` — `AddVertex`** — the original set `BeginIndex`/`EndIndex` to 0
  and derived `IsHole` from `Direction` *before* any real geometry existed;
  the intent is kept but made explicit.
- **`SpatialReader.cs` / `SpatialWriter.cs`** (formerly `ShapefileReader`/
  `ShapefileWriter`) — deterministic disposal of OGR handles (`using var` on
  DataSource/Layer/Feature); no more hardcoded `C:\Software\GDAL GISInternals`
  paths — the native runtime is discovered via `PATH` / `GDAL_DATA` / `PROJ_LIB`.
- **`Reprojector.cs`** — the gdal 3.11.3 C# binding exposes the
  `CoordinateTransformation` handle constructor but not its `Transform`
  method (a known OSGeo binding gap), so reprojection calls the stable GDAL
  C API directly via P/Invoke against the native library.

## Intentionally unfixed: the original R-tree

`Nsi.Geospatial/Spatial/RTreeManager.cs` and `RTreeNode.cs` were **restored
verbatim** from master (namespace changes only, all original typos included).
The known defects are preserved on purpose:

- `split()` double-parenting,
- `getMBRoverlap` containment gate (returns 0 when the query box contains
  the node box),
- `buildChildOptions` reading the stale `cumulativeOverlap`/`siblingOverlap`
  instance properties,
- the `Math.Max(overlap, 1)` floor in `getMBRoverlap`.

Consequences, by design:

- `RTreeTests.BulkInsert_AllFeaturesFindableByPoint` and
  `RTreeTests.GetEndNodes_LeavesHoldAllFeatureIndices` assert *correct*
  behavior the original algorithm violates, so they fail (or are skipped
  with a reason) — that's evidence, not a regression.
- `SpatialJoins` selects join candidates by scanning the collection instead
  of querying the tree, because the original `getMBRoverlap` gate misses
  contained boxes (see the comment in `NearestPointsToPolygons`).
- New geometry code should use the corrected `BoundingBox.Overlaps` (fix #15)
  rather than the legacy `RTreeNode.getMBRoverlap`.
