# Issues — open work

Open defects only; closed rows are **deleted** — recover with `git log --grep 'fix(P-xx)'`. Numbers are never reused or renumbered, and merged rows keep every number they absorbed. Highest in use: **P-70**. Retired: P-71/P-72 (they were P-02, P-43). Cited-but-undefined and so reserved: P-20, P-48, P-54, P-55, P-59, T-23, `P-02`/`D-E`, and T-17/P-06/P-65 (named by `FieldTypeTests`, `FieldTypes`, `OgrFieldTypes`) — once source names an id it stays reserved.

**Rules**
- **Warnings are the maintainer's call** — options named, never a blocker, never grounds for a public API change. Fix, suppress or ignore is yours.
- `Guard` is the only evidence field; `none` means a fix could land and revert green. **A behaviour change with no test asserting the observable result is not closed** — three commits to one distance loop shipped a crash, a silent wrong answer, then the fix, all green. If the guard is hard to write, the method's visibility is the bug (P-02).
- **`dotnet test`'s case total is the diff that matters** (CI prints none). A build that recompiles nothing prints no warnings: clean-build before reading either.
- **Assert the externally determined answer** — exact equality also catches false positives; a bound derived from internals is weaker. Never pin a value §0 leaves open; where today's behaviour must be pinned to be useful, say so here. No commented-out guards. **A test's data is part of its claim:** disjoint boxes and dead-centre queries cannot fail on overlapping data or a near miss.
- Deleting dead code beats annotating it; causing a defect to disappear beats testing around it. A sentinel you must compare against to detect is the defect.
- A row over ~6 lines is a design question: `CHANGES_*.md`, link it, keep the row. No CI state, no annotation counts, no "verified at `<sha>`".

## 6. Breaking changes that shipped, before 0.1.x — note in the changelog, once

None owed to a rule id; this records what is now true of the API. `Reprojector` removal (public static; the P/Invoke path returned transposed coordinates for geographic CRS) · `getArea`/`getPerimeter` → `Area`/`Perimeter` · `FeatureCollection` → `Features` **and** `.Features` → `.FeatureSet` (the second compiler-forced — a member can't share its type's name — and the one that touched every call site) · `SpatialWriter.Write`'s parameter `collection` → `features`, breaking named-argument callers against the concrete class only · `Reprojection` namespace, if P-61 lands · `AttributeColumn.CsharpType`/`FieldTypeToType` now return `typeof(double)` for `SingleFT`, where they returned `typeof(float)` — the declaration moved to match what `Coerce` always boxed (there is no `Math.Round(float, int)`, and `SetOgrField` casts to `double` regardless). `SingleFT` is now indistinguishable from `FloatFT` in every mapping — `OFTReal`, `typeof(double)`, `GetFieldAsDouble` — so it is either real end to end or deleted; `CoerceBoxesWhatTheColumnDeclares` cannot arbitrate, because it asserts the two halves agree rather than which is right.
